# LibreTranslate API - Комплексная техническая документация

Пример технической документации для open-source сервиса машинного перевода [LibreTranslate](https://github.com/LibreTranslate/LibreTranslate), разработанный в рамках подхода **Docs-as-Code**.

Проект демонстрирует проектирование контрактов REST API, создание пользовательских руководств для разработчиков и оформление эксплуатационной документации в соответствии со стандартами ЕСПД (ГОСТ 19).

## Состав проекта и артефакты

| Компонент | Технологии / Стандарты | Описание | Статус |
| :--- | :--- | :--- | :--- |
| **Спецификация API** | OpenAPI 3.1.0 (Swagger), YAML | Описание эндпоинтов (`/translate`, `/translate_file`, `/detect`, `/languages`), схем данных и кодов ошибок (`openapi/openapi.yaml`). | Готово |
| **Документация ЕСПД** | AsciiDoc, ГОСТ 19.504-79, Asciidoctor PDF | «Руководство программиста» с модульной структурой исходников (`gost-docs/`) и сборкой в PDF. | В работе |
| **Портал документации** | Docusaurus, MDX, Swagger UI | Веб-портал с разделами *Quickstart*, *Guides* (постредактура машинного перевода) и интерактивным справочником API. | В плане |

## Структура репозитория

```text
libretranslate-docs/
├── gost-docs/                  # Исходники документации по ГОСТ 19.504-79 (AsciiDoc)
│   ├── index.adoc              # Главный сборочный файл с метаданными и переменными
│   └── sections/               # Модульные разделы документа (include)
├── .gitignore
└── README.md
```

## Локальный запуск тестового стенда

Для проверки примеров запросов и тестирования эндпоинтов используется локальный контейнер LibreTranslate:

```bash
docker run -ti --rm -p 5000:5000 libretranslate/libretranslate --load-only en,ru,zh
```

После запуска сервис доступен по адресу `http://localhost:5000`.
