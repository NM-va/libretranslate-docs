== Назначение и условия применения программы

=== Назначение программы
Программный интерфейс {product-name} предназначен для интеграции функций автоматического машинного перевода текстов и документов в прикладные информационные системы по протоколу HTTP/HTTPS.

Основные решаемые задачи:

• перевод текстовых фрагментов в формате text и html между поддерживаемыми языковыми парами;
• автоматическое определение языка исходного текста;
• пакетный перевод файлов (.txt, .odt, .docx, .epub, .srt);
• получение актуального списка поддерживаемых языков и направлений перевода.

=== Условия применения
Для корректного взаимодействия с {product-name} клиентское приложение должно соответствовать следующим требованиям:

. Наличие сетевого доступа к серверу развертывания API по протоколу HTTPS (версия TLS 1.2 и выше).
. Поддержка кодировки UTF-8 при формировании тела запроса и обработке ответов.
. Наличие действующего ключа доступа (api_key), если на целевом сервере включен режим авторизации.

NOTE: При использовании публичных инстансов {product-name} действуют ограничения на частоту запросов (Rate Limiting). Для высоконагруженных систем рекомендуется локальное развертывание сервиса.
