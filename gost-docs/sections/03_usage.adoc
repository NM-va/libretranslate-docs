== Обращение к программе

Взаимодействие клиентских приложений с сервисом {product-name} осуществляется по протоколу HTTP в соответствии с архитектурным стилем REST.

Базовый адрес локального тестового стенда: `http://localhost:5000`.

=== Авторизация и заголовки запроса

Если на сервере активирован режим проверки ключей доступа (переменная окружения `LT_API_KEYS=true`), клиент обязан передавать действующий ключ `api_key` в теле каждого POST-запроса.

Обязательные HTTP-заголовки для передачи текстовых данных:

[source,http]
----
Content-Type: application/json
Accept: application/json
----

Для загрузки файлов через метод `/translate_file` используется заголовок `Content-Type: multipart/form-data`.

=== Перечень программных интерфейсов (эндпоинтов)

[cols="1,2,4", options="header"]
|===

| Метод HTTP | Путь (Endpoint) | Назначение вызова

| `GET`
| `/languages`
| Получение перечня установленных на сервере языков и доступных направлений перевода.

| `POST`
| `/detect`
| Определение языка переданного текстового фрагмента с оценкой достоверности.

| `POST`
| `/translate`
| Выполнение машинного перевода текста или HTML-разметки.

| `POST`
| `/translate_file`
| Загрузка документа и получение ссылки на скачивание переведённого файла.

| `GET`
| `/health`
| Проверка готовности сервиса к обработке запросов (Healthcheck).
|===

=== Пример обращения к методу перевода текста

[source,bash]
----
curl -X POST http://localhost:5000/translate \
  -H "Content-Type: application/json" \
  -d '{
    "q": "你好，世界！",
    "source": "zh",
    "target": "ru",
    "format": "text"
  }'
----
