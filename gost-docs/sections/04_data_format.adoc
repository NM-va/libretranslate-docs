== Входные и выходные данные

Обмен данными между клиентом и сервисом осуществляется в кодировке **UTF-8** с использованием формата **JSON** (за исключением бинарной передачи файлов в запросе `/translate_file`).

=== Входные данные метода `POST /translate`

[cols="2,1,1,4", options="header"]
|===

| Параметр | Тип | Обязательность | Описание и допустимые значения

| `q`
| `string`
| Да
| Исходный текст или HTML-фрагмент для перевода.

| `source`
| `string`
| Да
| Код исходного языка по стандарту ISO 639-1 (`en`, `ru`, `zh`) или значение `auto` для автоопределения.

| `target`
| `string`
| Да
| Код целевого языка перевода (`en`, `ru`, `zh`).

| `format`
| `string`
| Нет
| Формат входного текста: `text` (по умолчанию) или `html`.

| `alternatives`
| `integer`
| Нет
| Количество дополнительных вариантов перевода (целое число от `0` до `5`, по умолчанию `0`).

| `api_key`
| `string`
| Условно
| Персональный ключ доступа (обязателен при включённой авторизации на сервере).
|===

=== Выходные данные метода `POST /translate`

При успешном выполнении запроса (HTTP-код `200 OK`) сервер возвращает JSON-объект со следующими полями:

* `translatedText` (`string`) - основной вариант переведённого текста.
* `alternatives` (`array[string]`) - массив альтернативных переводов (возвращается при значении входного параметра `alternatives > 0`).

.Пример выходных данных (HTTP 200 OK)
[source,json]
----
{
  "translatedText": "Привет, мир!",
  "alternatives": []
}
----
